# Project AHTI

## Description
Project AHTI is a flight-ready, 1 kN pressure-fed liquid rocket engine developed by the Aalto Space Association for future integration into a European Rocketry Challenge (EuRoC) flight vehicle. The immediate primary objective is completing a successful qualification hot-fire test.

## Current Project Status
2026-09-16 The mission requirements review (MRR) was passed.

The current mission is: Successful hot Fire of a Euroc compatible 1kN liquid rocket engine before May Day of 2027. 

Project success is measured by:
* Being on schedule
* Producing useful thrust during testing
* Building the engine as per requirements
* HAVING FUN!

The following were chosen as the starting design parameters:
* **Thrust:** 1.0 kN nominal
* **Total Impulse:** 6000 Ns (~6 second burn duration)
* **Propellants:** Nitrous Oxide ($\text{N}_2\text{O}$) & Isopropanol (IPA)
* **Pressurization:** Gaseous Nitrogen ($\text{N}_2$) regulation
* **Chamber Pressure ($P_c$):** 20 – 25 bar
* **Tank Pressure ($P_{\text{tank}}$):** 50 bar
* **Engine Target Dry Mass:** 11.5 kg target
* **System Diameter:** 80 – 105 mm outer diameter
* **Design Philosophy:** Euroc Compatible Cost-Effective

## Main Repository Structure

The repository is split between sub disciplines: lead, structure, fluids, propulsion, operations/safety, and avionics, with each sub discipline having a system description with the main parameters of their respective systems and system files
